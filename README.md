# Pet Care Appointment Booking and Health Records Telegram Bot

A Telegram bot for veterinary clinics, pet groomers, and dog daycare facilities. Handles appointment booking requests, sends vaccination reminder alerts, stores pet health record summaries, collects post-visit satisfaction surveys, and notifies owners when their pet is ready for pickup. Multi-pet household support with individual health profiles for each animal. Bilingual support for English and Spanish.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
